# Agric

Agriculture-oriented icon set, born as a web font based on Font Awesome 4 and
extended with icons for the Ekylibre ecosystem.

[![CI](https://github.com/ekylibre/agric/actions/workflows/ci.yml/badge.svg)](https://github.com/ekylibre/agric/actions/workflows/ci.yml)

## Overview

Agric ships about 1 950 icons in every format useful for the web and mobile apps:

| Format | Path | Use |
|---|---|---|
| Web font WOFF2 / WOFF / TTF | `app/assets/fonts/` (gem), `dist/fonts/` | Rails asset pipeline, CSS |
| SCSS / CSS (`.icon-<name>` classes) | `app/assets/stylesheets/` (gem), `dist/scss/`, `dist/css/agric.css` | Web |
| SVG, one file per icon (`fill="currentColor"`) | `dist/svg/<name>.svg` | Web, design tools |
| SVG sprite (`<symbol id="agric-<name>">`) | `dist/sprite/agric.svg` | Web (`<use href="agric.svg#agric-cow">`) |
| PNG 24, 36, 48, 72 and 96 px | `dist/png/<size>/<name>.png` | iOS @1x/@2x/@3x, Android mdpi→xxxhdpi, e-mails |
| Android VectorDrawable (24dp) | `dist/android/drawable/agric_<name>.xml` | Android (`@drawable/agric_cow`) |
| iOS asset catalog (vector, template rendering) | `dist/ios/Agric.xcassets/` | iOS (`UIImage(named: "cow")`) |
| Glyph maps | `dist/agric.json`, `dist/react-native/agric.json` + `Agric.ttf` | JS apps, `react-native-vector-icons` |
| Preview | `dist/preview.html` | Browse and search the icons |

All formats are generated from the same glyph outlines, so they render exactly the
same shape. `dist/` is built by `npm run build` (it is not committed).

## Installation

### Ruby on Rails

Add this line to your application's Gemfile:

```ruby
gem 'agric'
```

Then `@import "agric";` in a stylesheet (or `*= require agric`).

### npm

```bash
npm install @ekylibre/agric
```

```js
import '@ekylibre/agric/css';        // web font + .icon-* classes
import glyphs from '@ekylibre/agric'; // { family, version, icons: { cow: { code, char } } }
```

## Usage

```html
<i class="icon-cow"></i>                                          <!-- web font -->
<svg width="24" height="24"><use href="sprite/agric.svg#agric-cow"/></svg>  <!-- sprite -->
```

```scss
.my-button { @include icon($agric-icons-tractor); }
```

## Build

Requirements: Node.js ≥ 20.

```bash
npm ci
npm run build        # validate + gem assets + dist/ (all formats)
npm run build:fonts  # validate + gem assets only (fonts and SCSS in app/assets)
npm run validate     # check manifest.json and glyphs/ only
npm run check        # what CI runs: fails if app/assets is not up to date
```

`./compile` is kept as a shortcut for `npm run build`.

### Sources

- `manifest.json` is the single source of truth: for every icon, its code point
  (in the Unicode private use area `E000`–`F8FF`), its source and, for imported
  icons, its license and original URL.
- `glyphs/<name>.svg` holds the drawing of each icon (1000 units high).
- `scripts/` holds the build (`build.mjs`), the checks (`validate.mjs`) and the
  importer (`import.mjs`).

The fonts and stylesheets in `app/assets` are generated and committed because the
gem serves them. Do not edit them by hand.

## Add an icon

### Draw your own

1. Draw a monochrome, filled SVG (no strokes) in a 1000×1000 viewBox, and save it as
   `glyphs/<name>.svg`. The name is lowercase kebab-case (`irrigation-pivot`).
2. Declare it in `manifest.json` with the next free code point in the private use
   area: `"irrigation-pivot": {"code":"e101","source":"ekylibre"}`.
3. Run `npm run build` and check the icon in `dist/preview.html`.
4. Commit `glyphs/`, `manifest.json` and `app/assets/`.

### Import from an open icon set

Only icons under a license compatible with an MIT package without per-icon
conditions are accepted: MIT, ISC, CC0-1.0, Apache-2.0, OFL-1.1. Sets checked so far:

| Set | License | Style | Import mode |
|---|---|---|---|
| [Lucide](https://lucide.dev/) | ISC | stroke | `vector` |
| [Healthicons](https://healthicons.org/) | CC0-1.0 | filled / outline | `vector` |
| [Open Crop Icons](https://github.com/openfarmcc/open-crop-icons) | CC0-1.0 | colour illustrations | `trace` |

[SVG Repo](https://www.svgrepo.com/) and [icon-icons](https://icon-icons.com/) mix
licenses icon by icon (some require attribution or forbid commercial use): check the
license of each icon before importing it.

Requirements: [Inkscape](https://inkscape.org/) ≥ 1.2 (`INKSCAPE` env variable to
override its path).

1. List the icons in a batch file (see `sources/2026-11-import.json`):

   ```json
   [
     {"name": "hail", "url": "https://raw.githubusercontent.com/lucide-icons/lucide/1.70.0/icons/cloud-hail.svg",
      "source": "lucide", "license": "ISC"},
     {"name": "potato", "url": "https://raw.githubusercontent.com/openfarmcc/open-crop-icons/<sha>/icons/russet-potato/russet-potato.svg",
      "source": "open-crop-icons", "license": "CC0-1.0", "mode": "trace"}
   ]
   ```

   Pin URLs to a tag or a commit so the import can be reproduced.

2. Run `npm run import -- sources/<batch>.json`, then `npm run build`.

   - `vector` mode converts strokes to outlines and merges every shape with Inkscape.
   - `trace` mode turns a colour illustration into a silhouette (light colours and
     inner dark lines become cut-outs) and vectorizes it with potrace. It can be tuned
     per icon with `"trace": {"detail": 12, "highlight": 235, "border": 64, "radius": 9}`
     (see `scripts/import.mjs`).
   - Every icon is centered in a 850×850 box, like the existing ones.

3. Check the result in `dist/preview.html` (imported icons have a green border).
   Intermediate files are kept in `tmp/import/`.

## Troubleshooting

- **`npm run check` fails in CI**: run `npm run build:fonts` and commit `app/assets`.
- **`inkscape` not found or cannot read files**: the importer works in `tmp/import/`,
  inside the repository, so that the snap version of Inkscape can access it.
- **An icon renders filled where it should have a hole**: fonts use the nonzero fill
  rule. Draw holes with the opposite direction, or merge the shapes (Inkscape:
  *Path > Union*) before adding the icon.
